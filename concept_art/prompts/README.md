# Concept Art Prompts

Image generation prompts for *The Doors of Gods*, written for DALL-E / ChatGPT in an **ink and watercolor** style.

## Files

- [characters.md](characters.md) — portrait and scene prompts for named and unnamed characters
- [concepts.md](concepts.md) — thematic and cosmological prompts (Emergence, Decline, the Gateway Mechanic, Wild Gods, Readers of Decline)

## Style note

All prompts target a loose ink-and-watercolor illustration aesthetic — evocative rather than photorealistic, with visible brushwork and fine ink linework. The tone across prompts should feel like original fantasy book illustration: specific, atmospheric, slightly worn.

## Using these prompts

Copy the text inside the `> blockquote` directly into DALL-E or ChatGPT image generation. Each prompt is self-contained. If a result is close but not quite right, you can follow up with adjustments like:

- "More muted color palette"
- "Stronger ink linework"
- "Less detail on the background figures"
- "The figure should look older / younger"

When you generate something you want to keep, save it to the relevant folder in `concept_art/` using the naming convention in that folder's README.
