# Concept Art

Visual references and AI-generated concept art for *The Doors of Gods*.

## Folder Structure

- `characters/` — portraits, expressions, and character studies
- `locations/` — landscapes, cityscapes, interiors, and establishing shots
- `concepts/` — abstract or thematic art (Decline, Emergence, divine domains, etc.)
- `misc/` — anything that doesn't fit neatly above (artifacts, symbols, mood boards)

## Naming Convention

Use descriptive, lowercase, hyphen-separated names with a version suffix:

```
characters/relen-portrait-v1.png
characters/relen-portrait-v2.jpg
locations/solaven-skyline-v1.png
locations/vanaek-tavern-interior-v1.png
concepts/emergence-abstract-v1.png
```

Keep earlier versions if they're meaningfully different — they're useful reference even if a later version is preferred.

## Using Images in Obsidian

You can embed images in any wiki note with:

```
![[relen-portrait-v1.png]]
```

Obsidian will find the image anywhere in the vault, so no need for a full path.
